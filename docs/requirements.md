# VidNest 需求文档

VidNest 是一款完全离线运行的 Android 本地视频管理与播放应用。核心定位：

**扫描手机视频 + 按文件夹浏览 + 每个视频独立播放次数统计 + 每个视频独立断点续播 + 倍速播放。**

应用不依赖服务器、账号体系、云服务或网络 API。视频文件、播放历史、播放次数和断点记录均保存在本地。应用不修改、不移动、不删除用户的原始视频文件。

> 页面布局与交互的 ASCII 原型图见 [ui-prototype.md](ui-prototype.md)（与实现保持同步）。

## 1. 功能需求

### 1.1 首次启动与媒体扫描

- 首次启动引导用户授权访问本地视频，然后扫描设备中可访问的视频文件（MediaStore）。
- 展示扫描进度、已发现视频数量和错误信息。
- 支持首次全量扫描、手动重新扫描和增量更新（ContentObserver 触发）。
- 对新增、删除、重命名、移动的视频按既定策略处理（见 permissions-and-media-scanning.md）。
- 扫描不阻塞主线程；扫描失败、权限被撤销、存储不可用时不崩溃。
- 重复扫描不产生重复记录；一次扫描失败不清空已有数据。

### 1.2 按真实文件夹组织视频

- 首页展示视频文件夹（保留目录层级），文件夹展示视频数量。
- 支持进入文件夹、返回上级；文件夹内视频展示文件名、时长、大小、分辨率、播放状态。
- 支持按名称、修改时间、大小、时长排序；支持名称搜索。
- 不同目录的同名视频必须可区分；空目录不展示。

### 1.3 每个视频独立断点续播（最高优先级）

- 每个视频拥有独立的播放进度记录，持久化到 Room。
- 重新打开视频默认恢复其自身上次有效位置；首次播放从头开始。
- 播放中定期保存（不频繁写库）；在暂停、切换视频、退出播放器、播放结束、生命周期变化等关键时机保存。
- 进程被杀后已持久化进度可恢复；切换视频/旋转屏幕/重建播放器不会覆盖其他视频断点。
- 播放结束后默认标记"已看完"，下次从头播放；不得恢复到视频末尾。
- 对无效进度、超时长进度、时长变化进行校验。

### 1.4 每个视频独立播放次数

- 播放次数保存在 Room，与具体视频关联。
- 列表项展示播放次数；详情页展示播放次数、上次播放时间、上次位置、观看状态。
- 同一播放会话不因播放器重建、Activity 重建、页面切换而重复计数；暂停/恢复/拖动/倍速变化不触发计数。
- 精确计数规则见 playback-and-progress.md。

### 1.5 倍速播放

- 支持 0.5x ~ 3.0x 共 9 档倍速（0.5/0.75/1.0/1.25/1.5/1.75/2.0/2.5/3.0）。
- 显示当前倍速；切换倍速不重置播放位置、不影响计数；默认 1.0x。
- 记住用户上次选择的倍速（全局），但视频不永久锁定倍速。

### 1.6 播放器界面

- 播放/暂停、当前时间/总时长、进度条 seek、快进快退、倍速、视频名、退出。
- 断点恢复提示；播放错误提示与重试；加载状态。
- 横竖屏适配、沉浸式播放、旋转时保留播放状态（不重复计数）。
- 退出播放器返回原文件夹（导航栈自然返回）。

### 1.7 视频列表与观看状态

- 每个视频保存：唯一标识、名称、URI、目录、大小、时长、修改时间、上次位置、播放次数、最近播放时间、看完状态、分辨率等元数据。
- 观看状态三种：未播放 / 正在观看 / 已看完，规则全局统一（见 playback-and-progress.md §5）。
- 支持按名称、最近播放时间、播放次数排序。

### 1.8 本地设置

- 重新扫描视频、查看媒体权限状态、默认排序方式、断点恢复行为、播放结束后行为、播放次数规则说明、清理失效索引（不删原始文件）、应用版本。
- 可选：添加 SAF 文件夹授权 / 移除授权。

## 2. 非功能需求

- 技术栈：Kotlin、Jetpack Compose + Material 3、Media3 ExoPlayer、Room、Coroutines + Flow、Gradle Kotlin DSL、分层架构、构造器注入 + 轻量 ServiceLocator。
- 中文界面优先；适配不同屏幕；正确处理加载/空/错误/权限状态。
- 默认不接入广告、统计 SDK、云服务。
- 不申请 MANAGE_EXTERNAL_STORAGE。
- 不在未验证设备上宣称兼容性（华为等兼容设备的设计注意事项见 permissions-and-media-scanning.md）。

## 3. MVP 验收标准

- 应用能扫描并展示可访问的本地视频，按真实目录组织。
- 每个视频可独立打开播放，拥有独立断点；切换不串号；进程被杀后断点可恢复。
- 每个视频有独立且持久化的播放次数；同一会话不重复累计。
- 支持常用倍速；播放结束后行为符合约定。
- 权限异常、文件失效、扫描失败不崩溃、不清空有效记录。
- 核心自动化测试通过；APK 构建成功或明确记录环境阻碍。

## 4. 明确不做

- 云同步、账号系统、广告、社交、在线流媒体、弹幕、字幕下载等联网功能。
- 视频编辑、转码、重命名（不改用户文件）。
- MANAGE_EXTERNAL_STORAGE、后台常驻服务。
