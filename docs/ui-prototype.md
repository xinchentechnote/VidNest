# VidNest UI 原型图（ASCII）

> 与当前实现保持一致（as-built）。宽度约 40 列，中文按 2 列宽绘制。

## 导航结构（底部 Tab）

```
底部 Tab：全部（默认）│ 文件夹 │ 播放历史 │ 播放统计

全部页：搜索（全应用唯一）+ 状态筛选 Tab + 全部视频
  └─点击/长按─► 播放器 / 详情 / 打开所在文件夹
文件夹页 ──► 层级下钻 ──► 播放器
播放历史 ──► 播放器 / 详情
任意页 ──► 播放器（播放列表同文件夹切换）──► 退出返回原页
```

## 1. 底部导航（全局，默认落在「全部」）

```
┌────────────────────────────────────────┐
│         ┌─────────────────┐           │
│         │ ● 全部  文件夹   │          │
│         │ 播放历史  播放统计│         │
│         └─────────────────┘           │
│                                       │
│ 全部：搜索 + 状态筛选 + 全部视频（默认首页）│
│ 文件夹：层级浏览根目录                │
│ 播放历史：按时间倒序（在看+已看完）   │
│ 播放统计：按天/周/月、按视频；        │
│           媒体时长 vs 实际时长对比    │
└────────────────────────────────────────┘
```


## 8. 长按菜单 / 倍速面板 / 播放列表

```
┌────────────────────────────────────────┐
│ 长按菜单：播放/查看详情/打开所在文件夹│
│ 倍速面板：[0.5x]…[3.0x] 九档九宫格    │
│ 播放列表：同文件夹视频（≥2 显示按钮） │
│   每项：名称 · 时长 · 已播放次数      │
│   当前项标「正在播放」，点击切换      │
└────────────────────────────────────────┘
```

## 9. 详情页 / 设置页（保持不变）

```
└────────────────────────────────────────┘
```
