# VidNest UI 原型图（ASCII）

> 与当前实现保持一致（as-built）。宽度约 40 列，中文按 2 列宽绘制。
> 各页面按导航层级组织；关键交互与规则以注释标注。

## 导航结构

```
库首页 ──► 文件夹页 ⇄ 子文件夹页（层级下钻，可多层）
  │              └──► 播放器（退出后返回原文件夹层级）
  ├──► 全部视频页 ──► 播放器 ⇄ 播放列表（同文件夹切换）
  │        └─长按─► 菜单：播放 / 查看详情 / 打开所在文件夹
  │        └──► 视频详情页 ──► 播放器
  └──► 设置
```
